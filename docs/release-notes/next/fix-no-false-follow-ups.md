**Keeping what matters**
- Saathi no longer adds a new detail to a kept card that you didn't mention. For example, "the papers are in the cupboard" no longer becomes an update of your kept LIC policy card. The update is kept only when you, or Saathi's question, named that card's subject. This is checked in code, not only in the instructions to the model.
- A second detail about the same kept card now joins the update card that is already waiting for Keep. Before, each detail made its own update card.
